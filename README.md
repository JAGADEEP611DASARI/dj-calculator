# DJ Calculator

A responsive calculator built with HTML, CSS Grid, and vanilla JavaScript.

## Features
- Addition, subtraction, multiplication, and division
- Clear, delete, decimal, percentage, and sign toggle
- Division-by-zero error handling
- Keyboard support
- Light/dark theme toggle
- Responsive layout

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. No Node.js installation or npm packages are required.
